# Assets Directory (`src/assets/`)

This directory is for assets processed and optimized by Astro's asset pipeline:
- `images/`: High-resolution source images, hero illustrations, project screenshots, and profile photos. (Astro will optimize them with `<Image />`).
- `icons/`: Custom SVG icons, badges, and vectors.
- `designs/`: UI mockups, raw design components, or vector assets.

> **Tip:** Static files that should bypass Vite/Astro processing (like `favicon.ico`, `robots.txt`, or direct downloads like `resume.pdf`) can be placed in `public/`.
